# 🛕 The Journey to Bappa (गणपति बप्पा मोरया)

> An atmospheric 2D devotional puzzle-adventure game following a young devotee's quest through locked rooms, dark labyrinths, and sacred temple sanctums to reach Lord Bappa's divine blessings.

---

## 📖 Story & Lore

On an auspicious Ganesh Chaturthi night filled with reverence, a young devotee awakens to a sacred calling—to reach the inner sanctum of Lord Bappa (*Vighnaharta*, the Remover of Obstacles). 

The path forward is guarded by ancient mechanisms, hidden passcodes, dark mazes, and the shadow of doubt known as *Vighna*. Guided by the sacred flame of faith (*Astha*), the player must collect lost artefact fragments, solve divine image sequence riddles, and unlock the final sanctum door to be bathed in Bappa's eternal golden light.

---

## 🎮 Gameplay & Level Overview

The game features immersive 2D exploration, interactive puzzle modals, mobile joystick and touch controls, fully voiced cutscenes, and atmospheric background audio.

### 🗝️ Level 1: The Devotee's Bedroom (Escape Room)
- Explore the bedroom to find study notes, carpet clues, and hidden keys.
- Unlock the bedside locker with a 3-digit keypad (`372`), obtain the Almirah Handle, and solve the 4-icon puzzle chest.
- Unlock the bedside drawer with Key 1 to retrieve the Screwdriver, open the screwed panel box, and collect the **Bedroom Key** and **Sacred Artefact Fragment (1/2)**.

### 🪔 Level 2: The Sacred Diya Labyrinth
- Carry the glowing holy Diya through a dark maze.
- Maintain the **Astha meter (100/100)** by avoiding shadowy Vighna encounters and seeking refuge near glowing Ganesha shrines.
- Discover sacred clues to find the exit portal leading into the living room.

### 🧩 Level 3: The Living Room & Morse Code Mechanism
- Inspect furniture, piano, trophies, and paintings for clues.
- Decode Morse code signals on the laptop (`.--. .- .. -. -` -> `PAINT`) to open the secret locker.
- Retrieve the second **Artefact Fragment (2/2)** and fuse them into the **Completed Sacred Artefact**.
- Enter door passcode `9277` on the digital keypad to enter the Mandir Sanctum.

### 🛕 Level 4: The Temple Sanctum & Divine Epilogue
- Walk up the sanctum approach to the lotus pedestal pillar.
- Insert the Completed Sacred Artefact into the pedestal slot to awaken the mechanism.
- Solve the scrambled 4-image sacred pilgrimage puzzle sequence (*Diya ➔ Trishula ➔ Mandir ➔ Ganesha*).
- Step into the radiant sanctum light to trigger the fully voiced 5-frame Epilogue Cutscene and celebration screen.

## 🚀 Getting Started & Installation

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0.0 or higher)
- [npm](https://www.npmjs.com/) (v9.0.0 or higher)

### Setup Instructions

1. **Clone the Repository**
   ```bash
   git clone https://github.com/AayushRaj0505/Journey-to-bappa-.git
   cd Journey-to-bappa-
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Start Development Server**
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:5173` (or the URL displayed in your terminal).

4. **Build for Production**
   ```bash
   npm run build
   ```
   The production bundle will be generated in the `dist/` directory.
